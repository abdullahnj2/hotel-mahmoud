# نظام إدارة حجوزات الفندق

## الملفات
| الملف | الوصف |
|---|---|
| `hotel-booking-system.jsx` | نموذج أولي تفاعلي كامل (واجهة النزيل + لوحة التحكم) — بيانات تجريبية في الذاكرة، جاهز للعرض فورًا |
| `schema.sql` | مخطط قاعدة بيانات D1 (الغرف، أنواع الغرف، الحجوزات، مستخدمو الإدارة) |
| `worker.js` | Cloudflare Worker (Hono) — واجهة API كاملة تتصل بـ D1 |

## البنية التقنية (نفس نمط jwatha-op)
```
React (واجهة النزيل + لوحة التحكم)
        │  fetch()
Cloudflare Worker (Hono API)  ──►  D1 Database
```

## خطوات النشر

**1. إنشاء قاعدة البيانات:**
```bash
wrangler d1 create hotel-booking-db
wrangler d1 execute hotel-booking-db --file=./schema.sql
```

**2. ربط القاعدة في `wrangler.toml`:**
```toml
name = "hotel-booking-api"
main = "worker.js"
compatibility_date = "2026-08-01"

[[d1_databases]]
binding = "DB"
database_name = "hotel-booking-db"
database_id = "<ضع المعرف هنا من الأمر السابق>"
```

**3. تثبيت Hono ونشر الـ Worker:**
```bash
npm install hono
wrangler deploy
```

**4. ربط الواجهة الأمامية:**
حاليًا الملف `hotel-booking-system.jsx` يستخدم بيانات تجريبية محليًا (`useState`) لتشاهد التجربة كاملة فورًا بدون أي إعداد. لربطه بالـ API الحقيقي، استبدل نقاط تحميل/حفظ البيانات بطلبات `fetch` إلى نقاط النهاية التالية:

| العملية | الطلب |
|---|---|
| عرض الغرف | `GET /api/rooms` |
| البحث عن غرف متاحة | `GET /api/availability?check_in=...&check_out=...&guests=...` |
| إنشاء حجز | `POST /api/bookings` |
| عرض كل الحجوزات | `GET /api/bookings` |
| تسجيل دخول/خروج/إلغاء | `PATCH /api/bookings/:id/status` |
| إحصائيات اللوحة | `GET /api/stats/overview` |

## نقاط تستحق القرار قبل الإنتاج
- **الدفع الإلكتروني:** النموذج الحالي يؤكد الحجز بدون دفع. لو تبي دفع مسبق أو عربون، نضيف بوابة دفع سعودية (مدى/Tap/PayTabs) عند خطوة التأكيد.
- **صلاحيات لوحة التحكم:** جدول `admin_users` جاهز، لكن الـ Worker حاليًا بدون طبقة تسجيل دخول — يحتاج JWT أو ربط بنظام الدخول المستخدم عندكم في jwatha-op.
- **الإشعارات:** فيه تعليق في `worker.js` عند إنشاء الحجز — نفس نقطة ربط تيليجرام/واتساب المستخدمة في jwatha-op ممكن تُستخدم لإشعار الاستقبال بحجز جديد فورًا.
- **قنوات خارجية:** إذا حبيت لاحقًا تربط الفندق بمنصات حجز مثل Booking.com أو Almosafer، تحتاج طبقة مزامنة إضافية (channel manager) — مش جزء من هذا النطاق حاليًا.

## تجربة النموذج الأولي
افتح `hotel-booking-system.jsx` — فيه زر تبديل أعلى الصفحة بين "واجهة النزيل" و"لوحة التحكم". جرّب:
1. احجز غرفة من واجهة النزيل بتواريخ مختلفة
2. بدّل للوحة التحكم → شوف الحجز في تبويب "الحجوزات" و"لوحة الإشغال"
3. سجّل دخول/خروج للنزيل من نفس الجدول
